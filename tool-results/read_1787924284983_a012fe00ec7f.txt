   702→  * Module-level docs in the same style as rust/cortexm-core/src/lib.rs
   703→    (algorithm summary, honest-recall-claims paragraph, citation to

   705→  * NsgIndex struct (dims, vectors flat f32, edges Vec<Vec<u32>>,
   706→    nav_node u32, k_build, n_edges) — exposes build/search/stats/
   707→    n_vectors/n_edges/nav_node/k_build to Python via #[pymethods].
   708→  * Build pipeline: kNN brute force → MRNG prune (Fu et al.) → tree-
   709→    traversal connectivity pass. The MRNG rule keeps edge (p,q) iff
   710→    no kept r satisfies dist(p,r) < dist(p,q) AND dist(q,r) < dist(p,q).
   711→    Tree-traversal pass: BFS from medoid; for any unreachable node i,
   712→    add an edge from i's nearest visited kNN to i (or medoid fallback
   713→    for pathological cases). This guarantees a greedy search starting
   714→    from the medoid can reach every node — without it, well-separated
   715→    clusters leave the search stuck in the medoid's cluster (verified
   716→    via the failing self-match test that motivated the fix).
   717→  * Search: greedy best-first from nav_node. Frontier = min-heap on
   718→    sim of size ef_search; candidates = min-heap on dist. Termination
   719→    when best candidate is worse than frontier's worst. A neighbor
   720→    enters candidate-expansion queue iff it survives into the frontier
   721→    (the standard NSG greedy admission rule that bounds expansion
